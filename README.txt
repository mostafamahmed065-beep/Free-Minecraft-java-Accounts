التشغيل على جهازك:
  npm install
  ADMIN_PASS=كلمتك_السرية npm start
  افتح http://localhost:3000   (زر ⚙️ للأدمن)

الرفع على Render / Railway (نوع Node):
  Build: npm install     Start: npm start
  أضف المتغير ADMIN_PASS بكلمة سر قوية جديدة (القديمة كانت ظاهرة في الكود).
  على Render أضف Disk وحدد DATA_DIR على مساره (مثلاً /data) وإلا تضيع الحسابات عند إعادة التشغيل.
